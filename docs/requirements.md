# 歌仔戲小百科網站 設計文件

日期：2026-11-13

## 1. 目的與範圍

- **用途**：課堂期末作業，以網址形式交給老師。
- **受眾**：學生、老師，以及沒接觸過歌仔戲的一般人。文字要淺白，專有名詞附白話解釋。
- **成功標準**：
  1. 老師點網址即可在電腦和手機正常瀏覽。
  2. 八個內容單元齊全，每頁有文字、圖片位置、影片位置。
  3. 翻牌配對與小測驗可正常遊玩。
  4. 所有文字與圖片都有可查證的出處。
- **已確認假設**：使用者目前沒有現成照片和影片，先做統一的圖片、影片預留位置，之後替換。

## 2. 技術決定

- 多頁式靜態網站，純 HTML、CSS、JavaScript，無建置流程、無框架。
- 「靜態」只代表網頁檔案不需要後端伺服器運算，不代表不能互動：音訊、影片、動畫、遊戲、測驗都由瀏覽器端的 JavaScript 與 HTML5 完成。
- 原始碼放在使用者已建立的 GitHub 倉庫；Cloudflare Pages（老師推薦的工具，免費）連結該倉庫，之後每次推送自動更新網站，交付時附完整設定步驟；GitHub Pages 為備案。
- 片頭動畫以 Remotion（用 React 程式碼製作影片的工具）製作，原始碼放在獨立資料夾 `video-src/`，與網站本身分開；網站只使用其輸出的 mp4，所以網站本身仍無建置流程。
- 視覺風格：古典與現代混合。米白底，深紅、金、墨黑為主色，標題用襯線字體（Noto Serif TC），內文用黑體，少量傳統紋樣作邊框與分隔線。

## 3. 網站結構

| 檔案 | 內容 |
| --- | --- |
| index.html | 首頁：標題區、單元入口卡片、遊戲入口 |
| history.html | 起源與歷史 |
| performance.html | 演出形式：民戲、外台公演、內台劇場公演 |
| roles.html | 角色行當 |
| xianxi.html | 扮仙儀式：三仙會、醉八仙、天官賜福（三種） |
| music.html | 經典四大曲調 |
| costume.html | 服裝道具 |
| backstage.html | 後台秘辛：劇團小禁忌、劇團冷知識 |
| games.html | 翻牌配對、看圖猜行當小測驗 |
| sources.html | 參考資料與圖片出處 |

目錄：`css/`、`js/`、`data/`、`assets/images/`、`assets/audio/`、`assets/video/`、`video-src/`（Remotion 原始碼，不上傳到網站發布內容中）。

## 4. 共用元件

- **樣式**：單一 `css/style.css`，以 CSS 變數管理配色、字級、間距；響應式，手機寬度不橫向捲動。
- **導覽列與頁尾**：由 `js/layout.js` 統一輸出，每頁共用；手機收成選單；單元頁底部有上一頁、下一頁連結。
- **名詞解釋**：以 `<abbr>` 或可點開的小提示呈現，詞條放在 `data/glossary.json`。
- **無障礙**：所有圖片附替代文字；顏色對比符合基本可讀性；遊戲可用鍵盤操作。

## 5. 素材處理

- 圖片：放在 `assets/images/`，每張附說明與出處（figcaption）。尚無素材時以統一比例的預留圖頂替。
- 影片：兩種方式並用。短片（單支約 30MB 內）放 `assets/video/`，以原生 video 元件播放；較長或來源為第三方的影片以 YouTube 嵌入（youtube-nocookie 網域），lazy loading。
- 音檔：放 `assets/audio/`，以原生 audio 元件播放；曲調頁提供「聽聽看」播放按鈕，一次只播放一個音檔。
- 活潑互動：頁面進場動畫、卡片翻轉、點擊展開、音效回饋（可關閉）；尊重使用者的「減少動態效果」系統設定。
- 文字：由 Claude 撰寫；寫作前先上網查證，所有來源列於 sources.html。使用者最後須自行核對內容。

## 6. 小遊戲

- **資料**：卡牌與題目集中於 `data/cards.json`，翻牌與小測驗共用。
- **翻牌配對**：
  - 三組牌組：行當配名稱、樂器配名稱、扮仙儀式配說明。
  - 難度：簡單 4 對、普通 6 對、困難 8 對；牌組內容不足 8 對時，困難難度改用混合牌組。
  - 顯示步數與時間；全部配對後顯示完成訊息與重玩按鈕。
- **看圖猜行當**：選擇題，題目與選項取自同一份資料，完成後顯示得分。
- 實作檔：`js/memory-game.js`、`js/quiz.js`。

## 7. Remotion 片頭動畫

- 約 20 到 30 秒的歌仔戲介紹短片，放在首頁最上方，可播放、可暫停，不自動出聲。
- 內容：標題、歌仔戲一句話介紹、八個單元名稱依序出現；配色與網站一致。
- 輸出 `assets/video/intro.mp4`（控制在約 30MB 內），並附一張封面圖。
- 若使用者之後有自己的照片或影片，可替換動畫內的圖片素材後重新輸出。
- 需要 Node.js 才能輸出影片；輸出完成的 mp4 會提交到倉庫，因此網站發布不需要執行 Remotion。

## 8. 驗證與上線

- 用 Playwright 在桌機與手機寬度截圖，檢查版面。
- 檢查所有內部連結沒有斷鏈。
- 以腳本或瀏覽器實際操作翻牌遊戲，確認配對、計步、完成判定正確。
- 附 Cloudflare Pages 上線說明（註冊、連結 GitHub 倉庫、設定發布資料夾、取得網址），GitHub Pages 為備案。
- 確認 intro.mp4 在網站上可正常播放與暫停。

## 9. 不在範圍內

- 後端、資料庫、使用者登入、留言功能。
- 多語言版本。
- 影片與照片本身的取得與授權（由使用者提供，或由 Claude 協助找開放授權素材並標註）。

## 10. 風險

- 內容正確性：歌仔戲相關說法各家略有出入，尤其曲調分類與扮仙儀式細節，需查證並在 sources.html 註明來源。
- 版權：圖片必須使用自拍、開放授權或取得同意的素材。
